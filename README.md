## Desc
The purpose of this lab is to do vector calculations.
These calculations include addition, subtraction and scalar multiplication.
The lab also can create and store vectors taken by user input.
## program commands
This progam is a vector calculator, the following actions can be called:
(*Note: x is any real numerical value)
- vectName = x x x (create a new vector)
- Vector math:
    - vectA +/- vectB
    - VectA * x
    - VectC = Vect A +/- VectB
- list (list all current vectors)
- quit
